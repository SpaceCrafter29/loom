  Three names, not three copies of "Arch Linux". systemd-boot titles an
  auto-discovered image from the PRETTY_NAME baked into it, and all three
  of these embed the same /etc/os-release -- so the images sit outside the
  directory it scans, and three entry files name them instead.

  Command-line editing is off. With full-disk encryption, letting anyone
  at the keyboard append init=/bin/sh would walk straight past the login.
  The rescue entry is the supported way in.

tty1 runs the session; tty2–tty6 are always plain login shells. A broken config in ~/.config/zellij cannot lock you out, and two fast session failures disable autostart for the rest of the boot and hand you a shell with an explanation.

The sixteen colours

1 · The font is approximated

The real console loads ter-132b — Terminus, a bitmap face at 16×32, set in /etc/vconsole.conf. Bitmap fonts cannot be delivered to a browser, so this page uses IBM Plex Mono. Expect the real thing to look harder-edged and slightly narrower.

2 · The colours are exact

Not approximated. These are the values setvtrgb writes at boot, and every theme in the system — zellij, neovim, btop, starship — refers to them by index, never by hex. Editing that one file restyles the whole machine.

3 · Found drawing this, now fixed

The update screen used to end “nothing to clean up” three lines after warning that a reboot was needed: only hard failures counted, so warnings never reached the summary. loomctl now keeps two counters — broken and needs-attention — because those are different things.

4 · Also found drawing this

The boot menu would have read Arch Linux three times. systemd-boot titles an auto-discovered image from the PRETTY_NAME inside it, and all three Loom images embed the same /etc/os-release — so the rescue entry would have been unidentifiable at exactly the moment you needed it.

The images now live in /EFI/loom, which systemd-boot does not scan, and three entry files name them. tools/check.sh checks that each entry points at an image the presets actually build.
